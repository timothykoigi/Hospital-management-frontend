
# Hospital Management System — Frontend

A React-based hospital management application providing dedicated interfaces for administrators, doctors and patients.

## Overview

This repository contains the frontend application for the Hospital Management System.

## Technology Stack

- React
- JavaScript
- Vite
- React Router
- Axios
- CSS

## Application Modules

- Administrator Dashboard
- Doctor Dashboard
- Patient Dashboard
- Authentication and Authorization
- Appointment Management
- Patient Management
- Medical Records
- Prescriptions
